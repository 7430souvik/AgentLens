# AgentLens

AgentLens is an observability platform for AI applications and LLM-powered agents.

It provides a dashboard and SDK to create projects, manage API keys, and track events generated by AI applications.

## ✨ Features

- 📊 AI application observability
- 🔍 Event tracking
- 🔑 API key management
- 🔐 JWT authentication
- 🤖 AgentLens SDK
- 📈 Project and event dashboard
- 🗄️ PostgreSQL + Prisma

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Node.js 18+
Bun
PostgreSQL
Clone the repository
git clone https://github.com/7430souvik/AgentLens.git
cd AgentLens
Install dependencies
bun install

📦 AgentLens SDK

AgentLens provides an SDK that applications can use to communicate with the AgentLens platform.

Installation

Using Bun:

bun add @souvik080/agentlens-sdk

Using npm:

npm install @souvik080/agentlens-sdk
Basic Usage
import { AgentLens } from "@souvik080/agentlens-sdk";

const agentlens = new AgentLens({
  apiKey: "YOUR_API_KEY",
});

The SDK can be used by an application to send observability data to the AgentLens backend.

SDK APIs may evolve as AgentLens is actively developed. Check the SDK package for the currently supported methods and configuration options.
